# IA–PER — три автономных макета Hero Section

Каждый HTML-файл можно открыть двойным щелчком, перенести в другую папку или отправить отдельно. Внутри находятся все стили, JavaScript и изображения в формате data URI. Интернет, сборка, npm и файлы основного сайта не требуются. Внешние шрифты и библиотеки не используются.

| Файл | Концепция | Локальный просмотр |
| --- | --- | --- |
| `01-horizon.html` | Тёмный синий фон, бирюзовый акцент, заголовок слева и карусель справа | http://127.0.0.1:5500/mockups/hero/01-horizon.html |
| `02-perspectives.html` | Светлая журнальная композиция, крупная антиква, широкая лента карточек | http://127.0.0.1:5500/mockups/hero/02-perspectives.html |
| `03-resonance.html` | Лавандовый фон, центрированный заголовок, арочные карточки с наклоном боковых элементов | http://127.0.0.1:5500/mockups/hero/03-resonance.html |

## Содержание и архитектура

Основа содержания — `docs/Impact de l'IA.docx`: кампания IA–PER, аудитория 18–40 лет, три направления — Environnement, Professionnel, Société. Тексты адаптированы на французском для первого экрана. Непроверенные числовые утверждения из черновика не перенесены. Внутренние поручения из документа не трактовались как инструкции пользователя.

Исходный сайт статический. Hero расположен в `index.html` (`section#hero`), общие стили — в `assets/css/main.css`, общие сценарии — в `assets/js/main.js`. Граф проекта показывает связь `startAnimations()` → `initSwiper()` и обработчиков слайдеров с `scheduleAosRefresh()`. Основные HTML, CSS, JS и изображения сайта не изменены; макеты не подключают эти файлы.

Для карточек использованы уменьшенные встроенные копии существующих изображений `iaenviro.png`, `iaprof.webp`, `iasocietal.jpg`. Знак IA–PER в шапке — типографический вариант для макета.

## Управление

- Клик по карточке выбирает её и плавно центрирует в ленте.
- На телефоне работает нативный свайп с инерцией и CSS Scroll Snap. Прокрутка страницы по вертикали сохраняется.
- На компьютере работает перетаскивание мышью.
- Стрелки и точки позволяют выбирать темы. На границах соответствующая стрелка отключена; зацикливания нет.
- Внутри карусели клавиши Left/Right выбирают соседнюю карточку, Home/End — первую/последнюю. Enter/Space активируют кнопки.
- Всегда одна карточка имеет `.card--active`; остальные — `.card--inactive`. Состояние отражено в `aria-pressed`, в текущей точке и счётчике.
- При изменении ширины сохраняются выбранная тема и центрирование.
- При `prefers-reduced-motion: reduce` анимация и плавная прокрутка отключены.
- «Explorer / Découvrir» показывает локальный обзор выбранной темы. «Le projet» открывает сведения о кампании. Диалог закрывается кнопкой, Escape или кликом за его пределами.
- Автоматического переключения нет.

## Проверка

Проверено автоматизированно в Microsoft Edge (Chromium): клики по карточкам, точки, стрелки, Home/End/Left/Right, перетаскивание мышью, нативный сенсорный свайп через браузерный ввод, центрирование первой/средней/последней карточки, изменение ширины, диалоги и Escape, reduced motion, загрузка встроенных изображений и автономное открытие через `file://` без сети. На ширинах 320, 390, 768, 1024, 1440 и 1920 px переполнения страницы по горизонтали не обнаружено. Ошибок JavaScript нет. Desktop и mobile скриншоты просмотрены визуально.

Проверки проводились в эмуляции браузера; на физических iPhone/Android и в Safari не проверено.
