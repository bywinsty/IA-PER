## Проверка по TDD и verification-loop

Сценарии получены из выбранных пользователем пунктов аудита. Новый файл: `tools/tests/home-visual-accessibility.spec.mjs`.

1. До изменения сайта выполнено `npx playwright test tools/tests/home-visual-accessibility.spec.mjs --workers=1`: **6 failed**. Три проверки воспроизвели неверный порядок/геометрию À propos, две — перехват нажатий разросшимися невидимыми иллюстрациями при удвоенном шрифте, одна — смещение одиночного логотипа на планшете. RED зафиксирован коммитом `4fb7005`.
2. После исправлений: `npx playwright test tools/tests/home-visual-accessibility.spec.mjs tools/tests/home-hero.spec.mjs tools/tests/about-story.spec.mjs --workers=3`: **23 passed (35,8 s)**, включая те же шесть сценариев.
3. `node tools/scripts/verify-headers.mjs`: **Header generator is idempotent across 6 pages**.
4. `npx playwright test tools/tests/header.spec.mjs tools/tests/content-integrity.spec.mjs --workers=3`: **37 passed (50,0 s)**.
5. MCP Playwright: снимки 375/768/1440 px, четыре desktop-состояния, hover-цвет CTA. MCP DevTools: вычисленные стили заголовков, вступления, подписей и первой главы, размеры ЕС.
6. `git diff --check`: без ошибок. Graphify обновлён после изменений.
7. После уточнения каскада мобильной сетки повторно выполнено `npx playwright test tools/tests/home-visual-accessibility.spec.mjs --workers=3`: **6 passed (12,1 s)**. В проверку добавлено сохранение полной ширины каждой карточки партнёра на 375 px; мобильный снимок обновлён.

Итого **60/60 целевых проверок прошли**. Изменены CSS и атрибуты HTML; прикладной JavaScript не менялся. Процент покрытия кода для CSS/HTML не измерялся. Это не полная сертификация WCAG и не проверка реального Safari/iOS. Удвоение вычисленных размеров шрифта — стресс-тест текста, не browser zoom.
